
# Python Writing Test

A command-line application developed in Python to evaluate typing accuracy through interactive text exercises.

## Features

- Three difficulty levels: Easy, Medium and Hard
- Word and character accuracy calculation
- Character error tracking and frequency analysis
- Continuous accuracy feedback
- Persistent score storage
- Exception handling

## Project Structure

| File | Description |
| --- | --- |
| `main.py` | Main menu and user interaction |
| `typing_utils.py` | Accuracy calculation, error analysis and score management |
| `easy.txt` | Easy difficulty text |
| `medium.txt` | Medium difficulty text |
| `hard.txt` | Hard difficulty text |

## Requirements

- Python 3
- No external dependencies

## Usage

Run the following command from the project directory:

```bash
python3 main.py
```

## Academic Context

Developed in 2024 as my first programming project at Blekinge Institute of Technology (BTH), with the primary objective of learning Python and applying fundamental programming concepts, including control flow, functions, data structures, file handling and exception handling.
